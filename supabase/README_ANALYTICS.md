# 📊 GA4(구글 애널리틱스) 설정 가이드

지금까지는 어떤 문제집/월드컵/궁합이 실제로 잘 되는지 볼 방법이 전혀 없었음.
이번에 GA4를 붙여서 핵심 퍼널(가입→플레이→완료→공유→결제)을 전부
이벤트로 남기게 만들었음.

## 1. GA4 속성 만들고 측정 ID 발급받기

1. https://analytics.google.com 접속 (구글 계정만 있으면 무료)
2. 관리(좌하단 톱니바퀴) > 속성 만들기 > 이름 아무거나(예: "밸런스게임 앱")
3. 비즈니스 정보 대충 넘기고 만들기 완료
4. 데이터 스트림 > 웹 추가 > 웹사이트 URL에 실제 배포 주소 입력
   (예: `https://내아이디.github.io/balancegame/`)
5. 생성된 스트림 클릭하면 상단에 **측정 ID**가 보임 (`G-XXXXXXXXXX` 형태)

## 2. 코드에 측정 ID 넣기

`src/utils/analytics.js` 맨 위:

```js
const GA_MEASUREMENT_ID = "여기에_GA4_측정ID를_넣으세요";
```

이 자리에 1번에서 발급받은 `G-XXXXXXXXXX`를 넣고 재배포.

**이 값을 안 넣어도 앱은 정상 동작함** (그냥 애널리틱스만 안 쌓임) - 나중에 아무 때나
켤 수 있음.

## 3. 지금 남고 있는 이벤트 목록

| 이벤트 | 언제 | 왜 중요한지 |
|---|---|---|
| `sign_up` | 프로필(닉네임/나이/성별) 처음 만들 때 | 진짜 신규 유저 수 |
| `login` | 카카오 로그인 성공 시 | 재방문/로그인 빈도 |
| `deck_complete` | 밸런스게임 문제집 다 풀었을 때 | 어떤 문제집이 완주율이 높은지 |
| `worldcup_play_start` / `worldcup_complete` | 월드컵 입장 / 우승자 결정 | 어떤 월드컵이 인기 있는지, 중도 이탈률 |
| `chemistry_test_complete` | 궁합 % 무료 공개 시점 | 궁합 링크 유입 후 실제 완주율 |
| `chemistry_detail_unlock` | 로그인 후 상세결과 열람 | 무료→로그인 전환율 (제일 중요한 지표) |
| `share` | 결과/초대장 공유 버튼 누른 직후 | 어떤 콘텐츠가 실제로 퍼지는지 (`content_type`, `method` 파라미터로 구분) |
| `purchase` | 토스 결제 승인 성공 | 실매출 (GA4 표준 전자상거래 이벤트라 자동으로 수익 리포트에 잡힘) |
| `ad_reward_claimed` | 보상형 광고 보고 에너지 충전 | 광고 재고 소진율 |

## 4. GA4에서 이렇게 확인하면 됨

- **탐색 분석 > 퍼널 탐색**을 새로 만들어서
  `chemistry_test_complete → share → chemistry_detail_unlock` 순서로 넣으면,
  "테스트 완료 → 공유 → 상대방 상세결과 열람"까지 실제 전환율이 한 눈에 보임
  (이게 이 앱 바이럴의 핵심 지표임).
- **수익 창출 > 전자상거래 개요**에서 `purchase` 이벤트가 자동으로 매출로 집계됨.
- 이벤트 화면에서 `content_type`, `method` 같은 파라미터별로 나눠보려면
  관리 > 맞춤 정의 > 맞춤 측정기준에 해당 파라미터를 등록해야 세그먼트가 잡힘
  (등록 안 해도 이벤트 자체는 계속 쌓이니 나중에 등록해도 데이터 안 날아감).
