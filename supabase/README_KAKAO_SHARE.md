# 💬 카카오톡 "바로 공유" 설정 가이드

지금까지 궁합/밸런스게임 결과 공유는 "이미지 다운로드 → 카톡에 직접 첨부"
방식이었음. 이번에 카카오 JS SDK(Kakao.Share)를 붙여서, **다운로드 없이
버튼 한 번으로 카톡 공유 시트가 바로 뜨도록** 만들었음.

## 1. DB 마이그레이션

Supabase 대시보드 > SQL Editor에서 `migration_024_kakao_share.sql` 실행
(공유 카드 이미지를 잠깐 올려둘 `share-cards` Storage 버킷 생성).

## 2. 카카오 JavaScript 키 발급 (로그인용 REST 키와는 다른 키!)

1. https://developers.kakao.com > 내 애플리케이션 > 이미 로그인 연동에 쓰고 있는
   앱 선택 (없으면 새로 만들기)
2. 앱 설정 > 요약 정보 > "JavaScript 키" 복사
3. 제품 설정 > 카카오톡 공유 > 활성화 ON
4. 플랫폼 설정 > Web 플랫폼에 **실제 배포 도메인** 등록
   (예: `https://내아이디.github.io`) — 이거 안 하면 공유 버튼 눌러도 조용히
   실패함 (콘솔에 에러가 뜸)

## 3. 코드에 키 넣기

`src/utils/kakaoShare.js` 맨 위:

```js
const KAKAO_JS_KEY = "여기에_카카오_JavaScript_키를_넣으세요";
```

이 자리에 2번에서 복사한 JavaScript 키를 넣고 다시 빌드/배포.

## 4. 동작 방식 (자동 대체됨)

- **키를 넣으면**: 궁합 초대장/그룹 공유/밸런스게임 궁합 신청 버튼을 누르면
  카드 이미지가 자동으로 업로드되고, 카카오톡 공유 시트가 바로 떠서 다운로드 없이
  링크+이미지가 한 번에 전송됨.
- **키를 안 넣으면(기본값)**: 예전 방식(이미지 공유 시도 + 링크 자동 클립보드
  복사)으로 그대로 동작함 — 아무것도 안 깨짐, 그냥 카톡 원터치 공유가 없을 뿐.

즉 이 설정을 지금 당장 안 해도 앱은 정상 동작하고, 나중에 키만 넣으면 바로
업그레이드됨.

## 5. 테스트 체크리스트

- [ ] Web 플랫폼에 실제 배포 도메인 등록함
- [ ] `kakaoShare.js`에 키 넣고 재배포함
